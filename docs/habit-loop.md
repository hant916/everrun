# Habit Loop

Onboarding does not end at the first demo. The point is the repeatable loop that
keeps giving you feedback.

The normal EverRun loop is:

```text
Shape one bounded task.
Run it.
Read the report.
Adjust the next pack.
Repeat.
```

## Daily workflow

```bash
everrun pack-shape start
everrun run
everrun report
```

## How to keep the loop healthy

- **Pick one bounded task.** Shape a single, well-scoped change at a time.
- **Keep scope small.** Smaller packs converge faster and produce clearer
  evidence.
- **Prefer validation-backed packs.** Packs with real validation commands give
  the judge something concrete to decide on.
- **Read the reports.** The report tells you the verdict, the evidence, and the
  next action.
- **Create the next pack from evidence.** Let what you learned in the report
  shape the next bounded task.
- **Use human review only when judgment is genuinely needed.** It is an
  exception, not a routine step.

## Why this works

EverRun is a bounded coding-agent runner. The value compounds when you run the
loop repeatedly: each accepted pack is validated, judged, and recorded, so the
next pack starts from evidence instead of guesswork.
