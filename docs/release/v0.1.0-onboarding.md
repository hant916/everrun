# v0.1.0 Onboarding

Canonical release entry for EverRun v0.1.0.

Docs are complete by being layered, not by front-loading complexity.

---

## Layer 1 — Three commands: get running

```bash
pip install everrun-0.1.0-py3-none-any.whl
cd your-project
everrun init
everrun demo
```

Do not show on this screen: `everrun doctor`, a backend matrix,
manual `.everrun/role-assignment.json` editing, or lengthy config.

---

## Layer 2 — Five-minute explanation: what just happened

`everrun init` checks your local environment, detects available coding agent CLIs,
configures the project, creates a demo pack, and prints the next command.

**One coding agent is enough to start.** Multiple agents improve fallback and
independent review, but are not required.

`everrun demo` runs a deterministic, no-model run so you can see the bounded
run loop, validation, decision, and report trail without needing model
credentials.

After the demo, the real loop:

---

## Layer 3 — Full onboarding path

```bash
everrun pack-shape start
everrun run
everrun report
```

**Shape** turns fuzzy intent into a bounded Impl Pack.
**Run** executes that Impl Pack with validation, judgment, and evidence.
**Report** shows what happened.

The habit:

```text
Install → Init → Demo → Shape → Run → Report → Repeat
```

## Layer 5 — Troubleshooting path

If `everrun init` cannot find a coding agent, it prints a clear remediation
message with a recommended install.

For environment diagnostics, run:

```bash
everrun doctor
```

`doctor` is a **diagnostic tool**, not a required step in the happy path.
Do not run `doctor` before `init` unless you are debugging.

## Release verification checklist

- [ ] wheel installs (`pip install everrun-0.1.0-py3-none-any.whl`)
- [ ] `everrun version` works
- [ ] `everrun init` works from a clean project
- [ ] zero-agent remediation is clear (recommends OpenCode + deepseek-v4-flash,
      tells user to rerun `everrun init`)
- [ ] single-agent mode is READY (not READY_WITH_WARNINGS)
- [ ] missing optional agents are not printed as default warnings
- [ ] `everrun demo` works
- [ ] `everrun pack-shape start` works
- [ ] `everrun run` works on the demo or documented sample path
- [ ] `everrun report` works
- [ ] README points to getting-started
- [ ] setup docs do not compete with new docs
- [ ] stale commands are absent
- [ ] no optional-agent scare lines in user-facing onboarding docs

---

## Reject this release if

- release docs only cover installation
- release docs omit shape
- release docs omit run/report
- README and getting-started disagree
- setup.md remains a competing onboarding guide
- doctor is presented as required before init
- single-agent mode appears degraded
- stale commands remain (`everrun --version`, `everrun todo`,
  `validation.env`, `PYTEST_ARGS`, `python everRun/planner.py`)
- user-facing docs show missing optional agents as warnings or problems
- docs become complete by becoming harder to use
